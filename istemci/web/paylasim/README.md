# Ortak Test Yayını

Bu klasörün ilk `hazirla.py` betiği Mustafa'nın özel ana deposundan boş hedefe aktarım içindir; özel yerel dağıtım/erişim dosyalarını bekler. Ortak depoda yeniden çalıştırılmaz.

Ortak depoda `guncelle.py` kullanılır. İş mantığı ve SQL değiştirilmeden web kaynaklarını `docs/` ile eşler. İlk paketteki derlenmiş Dart köprüsü özellikle korunur.

Paylaşım uyarlaması yalnız `erisim.js`, erişim sayfası, app/olaylar ayar yükleme çağrısı ve modül/hesap yerel hizmet sınırı mesajıdır. Giriş bilgileri açık ayarda bulunmaz. Bir kişinin dosyayı seçmesi başka tarayıcıya yetki vermez.

Yayın ayarı: GitHub Settings → Pages → Deploy from a branch → main → /docs → Save.
